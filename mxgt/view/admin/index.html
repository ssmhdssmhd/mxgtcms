插件说明

沫兮官替官解系统可在新版苹果CMS后台完美使用，支持在线更新，国内用户可通过 GitHub 镜像进行远程更新。 插件部署要求：
1. mxgt 文件夹必须放在苹果CMS的 addons 目录内，才能被正确启用和加载；
2. mxthxt 文件夹必须放在苹果CMS 根目录（与 addons 同级）。
更多信息请参见项目 README.md。
