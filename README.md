# 沫兮官替官解系统（mxgtcms）

> 项目名称：沫兮官替官解系统
> 项目代号：mxgtcms
> 当前版本：v0.0.24
> 更新日期：2026-09-15

---

## 一、项目需求（Requirements）

### 1.1 项目定位
- 沫兮官替官解系统是一款运行在 **新版苹果 CMS（macCMS v10）** 后台的官方替换 / 官方解析类插件系统。
- 采用**新版苹果CMS 插件规范**（fastadmin-addons：`info.ini` + 插件入口类 + `think\addons\Controller`），可**完美兼容新版苹果 CMS 后台**，完成**安装、启用、停用、配置、卸载**。
- 支持**在线更新**：插件自身可在后台在线检查并更新到最新版本。
- 支持**国内镜像远程更新**：托管于 GitHub 的更新源，国内用户可通过镜像（如 ghproxy）加速远程更新。

### 1.2 核心功能需求
| 编号 | 功能 | 说明 |
| ---- | ---- | ---- |
| F1 | 插件化安装 | 将 `mxgt` 放入苹果 CMS 的 `addons` 目录，后台「应用中心 → 应用插件」自动识别 |
| F2 | 启用 / 停用 | 苹果 CMS 后台一键启用、停用插件（state 写回 info.ini），无需手动改文件 |
| F3 | 一键卸载 | 后台卸载时自动删除元数据表（`__PREFIX__mxgt_meta`）并清理启用时复制的残留目录 |
| F4 | 后台配置 | 苹果CMS「应用插件 → 设置」与插件自带配置页双入口，配置持久化到 `config.php` |
| F5 | 在线更新 | 以 GitHub Releases **发行版**为更新源：独立「在线更新」页面展示**本地版本 vs 远程版本**对比，一键检查/升级：下载发行版更新包 → 备份 → 覆盖，保留配置与启用状态 |
| F6 | 国内镜像更新 | 更新源支持 GitHub 官方源与国内镜像源切换（含下载加速） |
| F7 | 官替 / 官解核心 | （后续迭代）官方接口替换、官方解析处理等核心能力 |

### 1.3 目录结构需求（重要）
苹果 CMS 根目录部署要求：

```
苹果CMS根目录/
├── addons/                  # 苹果CMS 插件目录
│   └── mxgt/                # 【必须】放于 addons 内，才能被后台正确启用加载
│       ├── info.ini         # 插件元信息（名称/版本/state 启用状态）
│       ├── Mxgt.php         # 插件入口类（安装/启用/停用/卸载/app_init 钩子）
│       ├── config.php       # 插件配置项定义（框架读写持久化）
│       ├── install.sql      # 安装SQL（建元数据表，__PREFIX__ 占位符）
│       ├── controller/      # 控制器（后台 Admin / 前台 Index）
│       └── view/            # 模板（admin/ 后台页、index/ 前台页）
├── mxthxt/                  # 【必须】放于苹果CMS根目录（与 addons 同级）
│   ├── core/                # 云端更新核心
│   │   └── Update.php       # 检查/下载(多镜像测速选优)/备份/覆盖
│   ├── config/              # 云端更新配置（GitHub 仓库 / 镜像 / 分支）
│   │   └── config.php
│   └── version/             # 组件版本信息
│       └── version.php
└── static/                  # 站点静态目录
    └── addons/
        └── mxgt/            # 插件静态资源（logo.png / bg.jpg 背景图，随发布包分发）
            ├── logo.png
            └── bg.jpg
```

> ⚠️ 部署约束：
> 1. `mxgt` **必须**放在苹果 CMS 的 `addons/` 目录内，否则无法被后台识别、启用和加载。
> 2. `mxthxt` **必须**放在苹果 CMS 根目录（与 `addons/` 同级），供 `mxgt` 调用云端更新能力。
> 3. 新版苹果CMS 插件识别条件：插件目录内必须同时存在 `info.ini` 与 `{插件名}.php`（即 `Mxgt.php`）。

### 1.4 环境要求
- 苹果 CMS：新版 macCMS v10（fastadmin-addons 插件框架，基于 ThinkPHP 5.1）
- PHP：5.6+（建议 7.x）
- 数据库：MySQL 5.5+（建议 5.7+）
- 服务器：Linux / Windows 均可，需支持 file_get_contents 或 cURL 访问外网（在线更新）

## 二、安装与使用

### 2.1 安装步骤（压缩包方式，推荐）
1. 下载发布压缩包（如 `mxgtcms.v0.0.24 202609152334.zip`，内含 `mxgt/`、`mxthxt/` 与 `static/` 三个目录），可查看下文「六、历史更新包」获取各版本包。
2. 解压后，将 `mxgt/` 整个文件夹上传至苹果 CMS 的 `addons/` 目录。
3. 将 `mxthxt/` 整个文件夹上传至苹果 CMS **根目录**（与 `addons/` 同级）。
4. 将 `static/` 目录与苹果 CMS **根目录 static/** 合并（缺目录就新建，内含插件 Logo 与背景图 `static/addons/mxgt/`）。
5. 登录苹果 CMS 后台 → 「应用中心 → 应用插件」，找到「沫兮官替官解系统」。
6. 点击 **启用**，即可使用（启用时自动完成元数据初始化）。

> 备选：也可以在「应用中心 → 应用插件 → 本地上传」直接上传压缩包安装。
> 默认站点未强制签名时可直接安装；若站点开启了
> `require_local_signature`（后台配置 addon.require_local_signature=1），
> 则需要带签名（package.manifest.json + package.sig）的安装包。
> 在线更新时若更新包内含 `static/` 目录，会自动同步覆盖根 `static/addons/mxgt/`。

### 2.2 启用 / 停用
- 后台插件列表直接操作「启用 / 停用」，状态写回 `info.ini` 的 `state` 字段，即开即用。
- **启用后自动注册后台侧边栏快捷菜单**（「沫兮官替官解系统」入口，指向插件首页看板），无需手动在「系统设置 → 快捷菜单」添加；停用 / 卸载时自动移除。
- 启用后插件页面入口：`/index.php/addons/mxgt/admin/index`（首页看板）、`/index.php/addons/mxgt/admin/config`（插件配置）与 `/index.php/addons/mxgt/admin/update`（在线更新）。

### 2.3 配置
- 方式一：苹果CMS 后台 → 应用中心 → 应用插件 → 沫兮官替官解系统 → **设置**（框架原生配置页）。
- 方式二：插件自带配置页（`/addons/mxgt/admin/config`），单栏配置表单；在线更新为独立页面（`/addons/mxgt/admin/update`，侧边栏直达）。
- 两处保存位置一致（均写回 `addons/mxgt/config.php`）。
- 配置项：更新源（GitHub 官方源 / 国内镜像源 / 自定义源）、GitHub 仓库、自定义更新地址、API 接口地址、**插件登录账号 / 插件登录密码**（`login_user` / `login_pass`，默认 `admin` / `admin888`，两者均空时跳过插件登录）。
- **登录**：点击后台侧边栏「沫兮官替官解系统」进入插件时，右侧内容区先弹出登录卡片，登录成功后进入左侧栏主界面（首页看板 / 插件配置 / 在线更新）。
- 界面设计：主色 `#657A7F`、辅色 `#B86B74`。
- **Logo**：插件自带默认 Logo（`static/addons/mxgt/logo.png`），页面顶部自动显示；如需自定义，覆盖该文件即可（建议 128×128 透明 PNG）。

### 2.4 卸载
- 后台插件列表点击「卸载」。
- 卸载流程：执行插件 `uninstall()`（删除 `__PREFIX__mxgt_meta` 元数据表、清理启用时复制到 `application/admin/view_new/` 与 `static_new/` 的残留），随后框架删除整个插件目录并刷新钩子缓存。

## 三、在线更新机制（F5 / F6）

### 3.1 操作方式
- 独立「在线更新」页面与首页看板均展示 **本地版本 vs 远程版本**，并提供：
  - **检查更新**：比对远端最新发行版版本与本地 `info.ini` 的 `version`。
  - **在线更新**：一键执行「检查 → 下载发行版更新包 → 备份 → 覆盖 addons/mxgt 与 mxthxt」。
- 更新完成后自动保留：站长的**插件配置**（`config.php` 用户值合并）与**启用状态**（`info.ini` 的 state）。
- 更新前的旧代码自动备份到 `runtime/mxthxt/backup_时间戳/`，成功后删除。

### 3.2 更新流程
1. 请求远端更新信息接口（GitHub Releases API，国内用户走镜像），获取最新发行版信息。
2. 比对远端版本号与本地版本号，有新版本时**优先匹配发行版中上传的更新包资产（zip）**，未匹配到则回退源码 zip（zipball）。
3. 下载更新包至 `runtime/mxthxt/`（镜像源自动加 ghproxy 前缀加速）。
4. 解压校验（须包含 `mxgt/info.ini` 或 `mxthxt/core/Update.php`）。
5. 备份当前代码 → 覆盖 `addons/mxgt/` 与根目录 `mxthxt/` → 合并保留配置与启用状态。
6. 刷新插件缓存完成更新。

### 3.3 更新源
| 源 | 说明 |
| ---- | ---- |
| GitHub 官方源 | `api.github.com` 直连，适合海外/直连用户 |
| 国内镜像源 | 默认按候选镜像自动切换（`ghfast.top` / `gh-proxy.com` / `ghproxy.net` / `mirror.ghproxy.com`），全部失败后自动回退官方源直连；下载同样多镜像自动切换 |
| 自定义源 | 支持填写自定义更新接口地址（需返回含 `tag_name` 与 `assets`/`zipball_url` 的 JSON） |

> 镜像候选列表可在 `mxthxt/config/config.php` 的 `mirror_api_urls` / `mirror_download_prefixes` 中维护，无需改代码即可增删镜像。
> 更新分支固定为 `main`（`mxthxt/config/config.php` 的 `branch`），插件后台默认隐藏、不可更改。

### 3.4 发布新版本（维护者）
1. 更新 `mxgt/info.ini` 的 `version` 与 README 版本日志。
2. 提交代码并在 GitHub 仓库打 tag（如 `v0.0.5`）。
3. 打包更新包（见 3.5 命名规则），在 GitHub **Releases 页面将该 zip 上传为该版本的资产（Asset）**。
4. 用户插件在线更新时自动按前缀匹配该更新包并下载升级。

### 3.5 更新包命名规则
发布压缩包命名格式：**文件名 + 版本号 + 时间**，例如：

```
MXGTV.5.14.4 202609080302.zip
mxgtcms.v0.0.5 202609142258.zip
```

即：`{插件名称}.{版本号} {yyyyMMddHHmm}`。在线更新按前缀 `mxgtcms` 匹配发行版资产（可后台配置）。
> 注：上传到 GitHub Release 后，资产文件名中的空格会自动替换为点号
> （如 `mxgtcms.v0.0.5.202609142258.zip`），在线更新按前缀匹配不受影响。

### 3.6 手动更新脚本（自动更新不可用时的兜底）
插件内置 `mxgt/manual_update.php` 手动更新脚本。当后台「在线更新」无法运行时
（页面打不开、鉴权异常、后台被禁等），可在服务器上通过 SSH 命令行手动更新，从
当前配置的 GitHub 仓库拉取最新发行版并覆盖 addons/mxgt 与 mxthxt（自动保留配置与启用状态）。

```
# 在苹果CMS根目录执行（脚本会自动定位目录）
php mxgt/manual_update.php          # 检查并更新到最新发行版（会交互确认）
php mxgt/manual_update.php --yes    # 跳过确认，直接更新
php mxgt/manual_update.php --force  # 忽略“已是最新”，强制重新拉取最新发行版覆盖
php mxgt/manual_update.php --help   # 查看帮助
```

> 说明：该脚本也支持直接通过浏览器访问执行（输出纯文本进度），但不建议暴露在公网，
> 请通过命令行在服务器上使用，并确保服务器具备外网访问更新源的能力。

## 四、版本管理规范

- 版本号格式：`vX.Y.Z`
- 进位规则：**百位进一位**
  - `v0.0.1` → `v0.0.2` → … → `v0.0.99` → `v0.1.0` → … → `v0.9.99` → `v1.0.0`
- 版本号记录位置：`addons/mxgt/info.ini` 的 `version` 字段（插件列表展示与在线更新对比均以此为准）。
- 每次更新 / 维护代码必须：
  1. 更新 `info.ini` 版本号与 `README.md` 版本号；
  2. 在 README「版本更新日志」追加记录；
  3. 代码审查通过后提交至 GitHub。

## 五、版本更新日志

### v0.0.17（2026-09-15）
- **修复登录「网络异常，请重试」**：
  - 根因：插件独立登录的登录提交动作为 `doLogin`，但 `_initialize()` 中动作名经 `strtolower` 后为 `dologin`，白名单未匹配导致登录请求被重定向回登录页（页面返回跳转而非 JSON），前端解析 JSON 失败提示「网络异常，请重试」。

  - 登录页增强：服务器返回非 JSON（如 500 / 跳转页）时给出带状态码的定位提示（「服务器返回异常（xx），请确认插件已更新到最新版本」），不再误报「网络异常」。
