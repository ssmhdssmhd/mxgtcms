# 沫兮官替官解系统（mxgtcms）

> 项目名称：沫兮官替官解系统
> 项目代号：mxgtcms
> 当前版本：v0.0.1
> 更新日期：2026-09-14

---

## 一、项目需求（Requirements）

### 1.1 项目定位
- 沫兮官替官解系统是一款运行在 **新版苹果 CMS（macCMS v10）** 后台的官方替换 / 官方解析类插件系统。
- 可**完美兼容新版苹果 CMS 后台**，通过苹果 CMS 标准插件机制完成**安装、启用、停用、配置、卸载**。
- 支持**在线更新**：插件自身可在后台在线检查并更新到最新版本。
- 支持**国内镜像远程更新**：托管于 GitHub 的更新源，国内用户可通过镜像（如 ghproxy）加速远程更新。

### 1.2 核心功能需求
| 编号 | 功能 | 说明 |
| ---- | ---- | ---- |
| F1 | 插件化安装 | 将 `mxgt` 放入苹果 CMS 的 `addons` 目录，后台「应用中心 → 应用插件」自动识别 |
| F2 | 启用 / 停用 | 苹果 CMS 后台一键启用、停用插件，无需手动改文件 |
| F3 | 一键卸载 | 后台卸载时自动删除插件数据表（`{pre}mxgt_config`）与菜单 |
| F4 | 后台配置 | 提供可视化配置页，配置项持久化到数据库，支持修改保存 |
| F5 | 在线更新 | 后台检测远端最新版本，下载更新包并覆盖升级 |
| F6 | 国内镜像更新 | 更新源支持 GitHub 官方源与国内镜像源切换 |
| F7 | 官替 / 官解核心 | （后续迭代）官方接口替换、官方解析处理等核心能力 |

### 1.3 目录结构需求（重要）
苹果 CMS 根目录部署要求：

```
苹果CMS根目录/
├── addons/                  # 苹果CMS 插件目录
│   └── mxgt/                # 【必须】放于 addons 内，才能被后台正确启用加载
│       ├── addon.php        # 插件主配置（安装/卸载/菜单/表结构）
│       ├── config.php       # 插件配置项定义
│       ├── version.php      # 插件版本信息（在线更新对比用）
│       ├── install.sql      # 安装SQL
│       ├── uninstall.sql    # 卸载SQL
│       ├── install.php      # 安装脚本（兜底）
│       ├── uninstall.php    # 卸载脚本（兜底）
│       ├── controller/      # 控制器（后台 Admin / 前台 Index）
│       ├── model/           # 数据模型
│       └── view/            # 模板
└── mxthxt/                  # 【必须】放于苹果CMS根目录（与 addons 同级）
    ├── config.php           # 云端更新配置（GitHub 仓库 / 镜像）
    ├── version.php          # 组件版本
    └── Update.php           # 云端更新核心（检查/下载/替换）
```

> ⚠️ 部署约束：
> 1. `mxgt` **必须**放在苹果 CMS 的 `addons/` 目录内，否则无法被后台识别、启用和加载。
> 2. `mxthxt` **必须**放在苹果 CMS 根目录（与 `addons/` 同级），供 `mxgt` 调用云端更新能力。

### 1.4 环境要求
- 苹果 CMS：新版 macCMS v10（基于 ThinkPHP 5.1）
- PHP：5.6+（建议 7.x）
- 数据库：MySQL 5.5+（建议 5.7+）
- 服务器：Linux / Windows 均可，需支持 file_get_contents 或 cURL 访问外网（在线更新）

## 二、安装与使用

### 2.1 安装步骤
1. 下载本仓库源码。
2. 将 `mxgt/` 整个文件夹上传至苹果 CMS 的 `addons/` 目录。
3. 将 `mxthxt/` 整个文件夹上传至苹果 CMS **根目录**（与 `addons/` 同级）。
4. 登录苹果 CMS 后台 → 「应用中心 → 应用插件」，找到「沫兮官替官解系统」。
5. 点击 **安装** → 点击 **启用**，即可使用。

### 2.2 启用 / 停用
- 后台插件列表直接操作「启用 / 停用」，状态即开即用。
- 启用后插件后台菜单显示「沫兮官替官解」「插件配置」两个入口。

### 2.3 配置
- 后台 → 应用中心 → 应用插件 → 沫兮官替官解系统 → 配置。
- 配置项：更新源（GitHub 官方源 / 国内镜像源 / 自定义源）、自定义更新地址等。
- 配置保存后写入数据库 `{pre}mxgt_config` 表。

### 2.4 卸载
- 后台插件列表点击「卸载」。
- 卸载时自动执行 `uninstall.sql`：删除 `{pre}mxgt_config` 数据表，并移除后台菜单。

## 三、在线更新机制（F5 / F6）

### 3.1 更新流程
1. 插件后台点击「检查更新」。
2. 根据配置的更新源请求远端最新版本信息（GitHub Releases API，国内用户走镜像）。
3. 比对远端版本号与本地 `version.php` 版本号。
4. 有新版本时下载更新包，解压后覆盖 `addons/mxgt/` 与 `mxthxt/`。
5. 更新完成后回写版本号，刷新缓存。

### 3.2 更新源
| 源 | 说明 |
| ---- | ---- |
| GitHub 官方源 | `api.github.com` 直连，适合海外/直连用户 |
| 国内镜像源 | 默认使用 `ghproxy` 等镜像加速，国内用户推荐 |
| 自定义源 | 支持填写自定义更新接口地址 |

### 3.3 更新包命名规则
更新包文件命名格式：**文件名 + 版本号 + 时间**，例如：

```
MXGTV.5.14.4 202609080302.zip
mxgt.v0.0.2 202609141200.zip
```

即：`{插件名称}.{版本号} {yyyyMMddHHmm}`。

## 四、版本管理规范

- 版本号格式：`vX.Y.Z`
- 进位规则：**百位进一位**
  - `v0.0.1` → `v0.0.2` → … → `v0.0.99` → `v0.1.0` → … → `v0.9.99` → `v1.0.0`
- 每次更新 / 维护代码必须：
  1. 更新 `version.php` 与 `README.md` 版本号；
  2. 在 README「版本更新日志」追加记录；
  3. 代码审查通过后提交至 GitHub。
